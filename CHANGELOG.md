# Changelog

## 1.0.30 – first public release

- **Overview:** this Mac at a glance (model, macOS, uptime, restart advice, pending updates), load as colored rings, clipboard history, sound and microphones.
- **Monitor:** CPU (cores, P/E), memory like Activity Monitor, GPU, temperatures and fans, disk with largest folders on request, network per app, VPN, battery, processes with sort switch, filters and safe quit.
- **Tools:** keep awake, network check, pending Munki and macOS updates, attached displays and devices, drives with safe eject, printers with stuck-job cancel, listening ports.
- **Sound:** overall volume, sound per app, mute all microphones, switch input and output devices.
- **Menu bar:** selectable live values next to the eye, alerts for lasting load, heat, memory pressure, full disk and empty battery.
- **Widgets:** every page arranged like widgets on a phone, compact and expanded panel.
- English and German; no admin rights, no account, nothing sent.
